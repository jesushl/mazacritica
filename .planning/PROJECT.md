# MazaCrítica

## Current Milestone: v0.1 Experiencia social de noticias

**Goal:** Convertir el prototipo visual actual en una experiencia frontend editorial-social clara, accesible y responsive, sin conectar todavía el backend.

**Target features:**
- Sistema visual consistente para la portada editorial.
- Feed de notas con filtros, búsqueda, pestañas y guardados simulados.
- Adaptación responsive para escritorio, tablet y móvil.
- Navegación por teclado, foco visible y semántica accesible.

## Product Purpose

MazaCrítica combina un portal de noticias con una experiencia de frontend inspirada en redes sociales para ayudar a la ciudadanía a descubrir noticias, consultar contexto y participar en conversaciones críticas sobre representantes populares y el poder público.

El producto debe distinguir hechos documentados, fuentes, estados de investigación y opinión. Las etiquetas sensibles deben usar lenguaje neutral y no presentar sospechas como hechos probados.

## Active Requirements

- REQ-001: Sistema visual editorial-social.
- REQ-002: Feed y controles de descubrimiento simulados.
- REQ-003: Responsive multiplataforma.
- REQ-004: Accesibilidad de interacción.

## Scope Boundaries

Este milestone no incluye integración con la API Django, nuevas pantallas de detalle, autenticación real, publicación de contenido ni modelado adicional del backend.
