# Investigación de stack — v0.1

## Base existente

- React 18 con Vite.
- CSS propio sin librería de componentes.
- ESLint configurado.
- Datos simulados en `frontend/src/App.jsx`.

## Recomendación

Mantener React, Vite y CSS propio durante este milestone. La interfaz ya tiene una dirección visual específica y una librería de componentes todavía sería una distracción. Consolidar tokens CSS, componentes semánticos y utilidades de estado antes de introducir dependencias.

## Restricciones

- No conectar todavía Axios ni la API Django.
- No introducir una solución de estado global para un feed simulado.
- Mantener la compilación actual con `npm run lint` y `npm run build`.
