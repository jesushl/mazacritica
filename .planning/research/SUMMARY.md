# Resumen de investigación — v0.1

## Decisiones

- Mantener React, Vite y CSS propio.
- Usar una sola lista editorial con búsqueda y filtros.
- Tratar etiquetas como vocabulario controlado y visible.
- Priorizar fuente, contexto y estado de la información.
- Adoptar WCAG 2.2 como referencia para teclado, foco visible y objetivos táctiles.

## Implicaciones para el milestone

El trabajo debe centrarse en convertir el borrador actual en un sistema visual consistente y usable en distintos tamaños. La integración con el backend y las nuevas vistas se dejan para un milestone posterior, pero la forma de los datos mock debe anticipar la API de notas, etiquetas y fuentes.
